# Portfólio — Isabelly Marinho

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, hospedado via GitHub Pages.

## Seções

- **Sobre Mim** — apresentação e link para download do currículo
- **Formação Acadêmica** — linha do tempo com cursos e instituições
- **Projetos** — cards com descrição, tecnologias e link para o repositório
- **Cursos & Certificações** — certificados obtidos
- **Hard & Soft Skills** — habilidades técnicas e comportamentais
- **Experiência Profissional** — histórico de experiências
- **Contato** — formulário e links para LinkedIn e GitHub

## Tecnologias

- HTML5
- CSS3
- JavaScript 

## Como rodar localmente

Basta abrir o arquivo `index.html` diretamente no navegador — não precisa de servidor.

## Deploy

O site está publicado via **GitHub Pages**.  
Acesse em: `https://isabellymarinho20.github.io/portifolio_webI/`
